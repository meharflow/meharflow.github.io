What's new

MeharFlow is updated whenever Flow changes, and as creators ask for features.

Version 1.0.1 Coming soon

In testing
  • 🎬 Animate button on image results - sends the image to Flow's video panel as the first frame and puts its shot number in the SHOT box, ready for that shot's video prompt.
  • One-click next shot - new ◀ ▶ buttons move the whole shot range forward or back in one click.
  • Exact single-shot runs - a range of one shot (77 to 77) now sends only that shot, not its sub-shots.
  • Memory that survives a reinstall - shot records, settings and references are kept in a backup file in your series folder and restored automatically.
  • Safer downloads - if Flow's 2K/4K menu fails, the original size is saved under the right shot name instead of nothing.
  • Page check at Start - if Flow changes its page, MeharFlow stops before sending anything and says exactly what changed.
  • The download button on each result sits above Flow's own Reuse prompt button, so both can be clicked.

Version 1.0.0

September 2026 - first release
  • Batch prompts from a linked .docx or .csv shot list, with a shot range and a pause every few shots.
  • Single Prompt - paste one prompt and send it straight to Flow.
  • Reference images tagged by exact name as chips (characters, locations, props).
  • Video workflow: prompt, speaker and length prepared - your start frame is never touched, you press Generate.
  • Downloads saved into your episode folders, named by shot number.
