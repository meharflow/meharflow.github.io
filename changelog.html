What's new

MeharFlow is updated whenever Flow changes, and as creators ask for features.

Version 1.0.4 Coming soon

Goes to the Chrome Web Store once 1.0.3 is approved
  • Correct a shot number right on Flow - every image and video result shows its SHOT label. Click it, type just the number (12 or 12b) and press Enter: the label, the ⬇ file name (SH_12B_Image / SH_12B_Video) and your memory file all use it from then on.
  • 🎬 Animate checks the Start frame first - if the image is not in Flow's Start slot, nothing is sent and the log says why.
  • Never charged twice after a reload - if the Flow page reloads right after Generate, that shot is not sent again. It is marked "may have been sent - check Flow" and the batch carries on.
  • Your own file names win - a name you type for a video is always the name it is saved under.
  • A safer memory file - after a reinstall your characters, props and places are merged back by name, and before the list ever gets shorter the old file is kept as MeharFlow_Memory.bak.json.
  • No more missing log lines, and Stop works at once after a failed shot.

Version 1.0.3 In review

Sent to the Chrome Web Store on 7 October 2026
  • Never a random file name. When MeharFlow is not sure which shot a result is, pressing ⬇ opens a small box with its best guess. Press Enter to save it under the shot name, or Esc to save nothing. The answer is remembered for next time.
  • Video progress on the Flow page - beside the MeharFlow badge: how many of the episode's shots already have a video, how many are left, with a progress bar.
  • Upscaled files show their size - SH_12_2K, SH_12_4K, SH_12_Video_1080p. An ordinary download made while an upscale is on its way keeps its own name.
  • Images as PNG, JPEG or original - chosen in the Download tab.
  • Reinstall without the rework - characters, props, places and the shot list come back from your series folder, and the prompt document is linked again when it is in the episode folder.
  • Model list updated for Flow's Nano Banana 2.1.
  • Safer sending - a shot is only counted as sent when Flow really starts it; Generate is never pressed twice; a second Flow tab can no longer take over a running batch; Stop never sends the same shot again.
  • Credit limit on every shot - MAX CREDITS is checked against Flow's own price before every automatic send.
  • Copied text from the Flow page no longer picks up "IMG" labels.

Version 1.0.2

Sent to the Chrome Web Store on 5 October 2026
  • More reliable shot names for downloads, and shots sent a moment apart keep both their records.
  • 🎬 Animate follows Automate Send - with it on, MeharFlow also presses Generate; with it off, Generate stays yours.
  • Stop and Pause always hold, even in the middle of sending a shot.
  • Big videos land in your folder - upscaled 1080p and 4K videos are saved into the episode folder under their shot name.
  • Run report - CSV, MD and PDF buttons in the Logs tab save every shot's status.
  • Folders your way - an episode folder can be Episode_106, EP106, 106 or a name; images and videos folders are found under any common name.
  • Create folders - one button makes the episode folder and its whole folder set. Nothing existing is touched.
  • Tabs renamed: Control is now Create, Queue is now Project.

Version 1.0.1

Sent to the Chrome Web Store on 30 September 2026
  • One-press downloads - the ⬇ button on a Flow result saves it straight into your folder under its shot name. If it cannot, the button turns yellow and says why (shot not known, clip not loaded yet, folder needs permission).
  • IMG / VID labels on Flow's results, so images and videos are told apart at a glance.
  • Open your folders - 📂 Open next to the images and videos folder shows what has been saved.
  • Videos can now find their shot number from Flow's own media list, for more files named by shot automatically.
  • Smaller buttons on Flow's results, and the Download list scrolls only up and down.
  • 🎬 Animate button on image results - sends the image to Flow's video panel as the first frame and puts its shot number in the SHOT box, ready for that shot's video prompt.
  • One-click next shot - new ◀ ▶ buttons move the whole shot range forward or back in one click.
  • Exact single-shot runs - a range of one shot (77 to 77) now sends only that shot, not its sub-shots.
  • Memory that survives a reinstall - shot records, settings and references are kept in a backup file in your series folder and restored automatically.
  • Safer downloads - if Flow's 2K/4K menu fails, the original size is saved under the right shot name instead of nothing.
  • Page check at Start - if Flow changes its page, MeharFlow stops before sending anything and says exactly what changed.
  • The download button on each result sits above Flow's own Reuse prompt button, so both can be clicked.

Version 1.0.0

September 2026 - first release
  • Batch prompts from a linked .docx or .csv shot list, with a shot range and a pause every few shots.
  • Single Prompt - paste one prompt and send it straight to Flow.
  • Reference images tagged by exact name as chips (characters, locations, props).
  • Video workflow: prompt, speaker and length prepared - your start frame is never touched, you press Generate.
  • Downloads saved into your episode folders, named by shot number.
